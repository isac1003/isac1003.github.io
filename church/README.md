# 교회 관리

교인 명단 · 주일 출결 · 기도제목 · 생일과 심방을 한곳에서 다루는 가벼운 웹앱입니다.

- **자료는 구글 드라이브의 스프레드시트 한 장**에 쌓입니다. 시트를 직접 열어 고쳐도 그대로 반영됩니다.
- **화면은 정적 HTML 한 장**이라 즉시 열립니다. 서버도, 사용료도, 설치할 앱도 없습니다.
- 조직은 **목장 › 순 › 교인** 구조이고, 권한은 **관리자 / 목장 / 순장** 세 가지입니다.
  순장은 자기 순만, 목장은 자기 목장 전체만, 관리자는 전부 봅니다.

```
휴대폰 화면 (GitHub Pages)  ──POST(JSON)──▶  Apps Script  ──▶  구글 스프레드시트
   church/index.html                        Code.gs            교인·출결·기도·심방·계정
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전부. 이 파일 하나로 동작합니다 |
| `apps-script/Code.gs` | 구글 시트를 읽고 쓰는 백엔드. Apps Script에 붙여넣습니다 |
| `apps-script/appsscript.json` | Apps Script 설정 (시간대·배포 방식) |

---

## 설치 (20분, 한 번만)

### 1. 스프레드시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 이름을 **교회 관리 대장** 정도로 바꿉니다.

### 2. 스크립트 붙여넣기

1. 상단 메뉴에서 **확장 프로그램 › Apps Script** 를 누릅니다.
2. 편집기에 있던 `function myFunction() {}` 을 모두 지웁니다.
3. 이 저장소의 `apps-script/Code.gs` 내용을 **전부 복사해서 붙여넣고** 저장(Ctrl+S)합니다.

### 3. 첫 실행

1. 편집기 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **실행**을 누릅니다.
2. 구글이 권한을 묻습니다. **권한 검토 › 계정 선택 › 고급 › (프로젝트 이름)(으)로 이동 › 허용**
   순서로 진행합니다. (본인이 만든 스크립트라 안전합니다.)
3. 아래 **실행 로그**에 이런 내용이 뜹니다. **비밀번호를 꼭 적어 두세요.**

   ```
   설치가 끝났습니다.
   스프레드시트: https://docs.google.com/spreadsheets/d/...
   관리자 계정을 만들었습니다.
     이름: 관리자
     비밀번호: 483920
   ```

   시트에 `계정` `교인` `출결` `기도제목` `심방` 다섯 장이 생겼는지 확인합니다.

### 4. 웹 앱으로 배포

1. 오른쪽 위 **배포 › 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. 아래처럼 맞춥니다.
   - **설명**: 아무거나 (예: 1차)
   - **다음 사용자 인증 정보로 실행**: **나**
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. **배포**를 누르면 이런 주소가 나옵니다. **복사해 두세요.**

   ```
   https://script.google.com/macros/s/AKfycb....../exec
   ```

> **"모든 사용자"로 열어도 괜찮은가요?**
> 주소를 아는 사람이 접근할 수 있는 건 로그인 화면까지입니다.
> 명단·연락처·기도제목은 이름과 비밀번호로 로그인해야 열립니다.
> 그래도 주소는 교회 밖에 흘리지 마시고, 비밀번호는 각자 다르게 정해 주세요.

### 5. 화면 열기

1. 휴대폰에서 `index.html` 이 올라간 주소를 엽니다.
2. 첫 화면에 4번에서 복사한 **웹 앱 URL** 을 붙여넣고 **연결하기**를 누릅니다.
   이 주소는 그 기기에 저장되므로 다음부터는 묻지 않습니다.
3. **관리자**를 고르고 3번에서 받은 비밀번호로 들어갑니다.
4. 들어가자마자 오른쪽 위 **⋯ › 비밀번호 바꾸기** 로 비밀번호를 바꿔 주세요.

### 6. 홈 화면에 추가 (권장)

- **아이폰**: 사파리에서 열고 공유 → *홈 화면에 추가*
- **안드로이드**: 크롬에서 열고 ⋮ → *홈 화면에 추가*

앱처럼 아이콘이 생기고, 주소창 없이 전체 화면으로 열립니다.

## 쓰기 시작하기

### 순서대로 하면 편합니다

1. **명단부터.** 명단 탭 → 오른쪽 아래 **+** → 이름·목장·순·생년월일·연락처를 넣습니다.
   목장과 순 칸은 한 번 입력해 두면 다음부터 자동완성으로 뜹니다.
2. **계정을 나눠 줍니다.** 관리자로 로그인하면 **계정** 탭이 보입니다.
   목자·순장마다 계정을 만들고 비밀번호를 정해 전달하세요.
   - 관리자 → 목장·순을 **비워 둡니다**
   - 목장 → **목장만** 채웁니다
   - 순장 → **목장과 순을 모두** 채웁니다
3. **주일마다 출결.** 출결 탭은 지난 주일 날짜로 열립니다.
   이름 옆 버튼을 눌러 표시하고 아래 **저장**을 한 번 누르면 끝입니다.
   같은 버튼을 다시 누르면 표시가 지워집니다.
4. **기도제목과 심방**은 생각날 때 그때그때 적어 두면 대시보드가 알아서 챙겨 줍니다.

### 대시보드가 알려 주는 것

- **이번 주 생일** — 오늘부터 이레 안에 생일인 분 (전화 아이콘을 누르면 바로 통화)
- **오래 못 뵌 분** — 28일 넘게 출석 기록이 없는 분
- **심방한 지 오래된 분** — 180일 넘게 심방 기록이 없는 분
- **최근 출석** — 최근 여덟 주 추이

기준을 바꾸려면 `Code.gs` 맨 위의 `LONG_ABSENCE_DAYS`, `VISIT_GAP_DAYS` 숫자를 고치고 다시 배포하세요.

## 알아 두실 점

**음력 생일** — 음력으로 표시만 하고, 알림은 시트에 적힌 월·일을 그대로 씁니다.
음력 생일을 챙기시려면 그해 양력 날짜를 생년월일 칸에 넣고 음력 표시를 켜 두시는 편이 확실합니다.

**시트를 직접 고쳐도 됩니다** — 엑셀에서 옮겨 붙이거나 시트에서 바로 수정해도 앱에 반영됩니다.
다만 **첫 줄(제목 줄)과 `ID` 칸은 건드리지 마세요.** 그 두 가지로 자료를 이어 붙입니다.
새 교인을 시트에서 직접 추가할 때는 `ID` 칸을 비워 두지 말고 `M-260822-a1b2` 같은
겹치지 않는 값을 넣어 주세요.

**계정 시트의 비밀번호** — 원문이 아니라 되돌릴 수 없게 변환한 값이 들어갑니다.
시트를 남이 보더라도 비밀번호는 알아낼 수 없습니다. 대신 잊으면 복구가 아니라 재설정입니다.

**비밀번호를 잊었을 때** — 대개는 관리자가 풀어 줍니다.
관리자로 로그인해 **계정** 탭에서 그분을 고르고 *새 비밀번호* 칸을 채워 저장하면 끝입니다.

관리자 비밀번호까지 잊었다면 Apps Script 편집기를 엽니다.
`Code.gs` 위쪽의 `비밀번호_재설정` 함수에 이름과 새 비밀번호를 적고,
함수 선택 칸에서 그 함수를 골라 **실행**하면 됩니다.

```js
function 비밀번호_재설정() {
  const 이름 = '관리자';
  const 새비밀번호 = '새로정한비밀번호';
  ...
```

실행이 끝나면 적어 둔 비밀번호는 지워 두세요.
관리자 계정을 두 개 두면 이런 일이 줄어듭니다 (`addAdmin('김목사', '비밀번호')`).

**연결이 끊겨도** 마지막으로 본 자료는 그대로 보입니다. 다만 그 상태에서 저장은 되지 않습니다.

**백업** — 스프레드시트에서 **파일 › 사본 만들기**를 이따금 해 두시면 충분합니다.

## 코드를 고칠 때

`Code.gs` 를 고쳤다면 **배포 › 배포 관리 › (연필) › 버전: 새 버전 › 배포** 를 눌러야
바뀐 내용이 반영됩니다. 새 배포를 만들면 주소가 바뀌니, 기존 배포를 수정하세요.

`index.html` 은 저장소에 올리면 그대로 반영됩니다.
